## 这份指南解决什么问题

<CardGrid stagger>
  <Card title="不是聊天壳，而是 Agent" icon="rocket">
    用 `ToolLoopAgent` 建立“读取事实 → 选择工具 → 执行动作 → 验证结果”的循环。
  </Card>
  <Card title="纯前端也能落地" icon="laptop">
    Agent、工具执行器与 Pinia Store 全部在浏览器运行，同时诚实处理 API Key 和 CORS 边界。
  </Card>
  <Card title="可控地修改业务状态" icon="approve-check">
    不让模型随意覆盖 JSON；通过 Zod、领域 Action、事务、Undo 与危险操作确认保护数据。
  </Card>
  <Card title="生产级聊天体验" icon="star">
    覆盖 reasoning、工具卡片、自动滚动、Markdown 安全、i18n、拖拽面板与性能预算。
  </Card>
</CardGrid>

> 本站面向需要把 AI 接入真实业务系统的前端团队。示例使用页面编辑器场景，但 Context、Tool、Transaction 与 Approval 模式可迁移到表格、工作流、后台管理和其他领域。
